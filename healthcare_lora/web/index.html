1 / Dataset integrity

PubMed 20k RCT. Official train/dev/test splits retained. PMIDs and full abstract hashes are checked across splits. Shared boilerplate sentences and near-duplicate content remain documented limitations.

2 / Controlled adaptation

PEFT + TRL completion-only supervised fine-tuning. Track rank, learning rate, seed, validation loss, adapter hashes, and selected checkpoint. Compare three configurations using validation macro-F1.

3 / Paired evaluation

Same examples, prompt, model revision, context budget, and scoring rules. Report accuracy, macro-F1, per-category recall, invalid outputs, and abstract-cluster bootstrap uncertainty.

4 / Deployment decision

Reject an adapter when gains are inconclusive, a category regresses too much, invalid outputs increase, or general capability retention has not been measured. The included retention suite is a smoke check, not a standard benchmark.
